# 90天雅思手写学习台（免费本机识别版）

这是一个面向 iPad 和 Apple Pencil 的学习网页。本次改版替换了依赖系统“随手写”转文字的单词与机经拼写答题方式。

- 不要求登录
- 直接在 Canvas 答题纸写字，保留原笔迹；支持笔粗、颜色、橡皮擦、撤销重做、可撤销清空与放大书写
- 按题目、方向和模块保存草稿；按作答次数保存历史，可回看并重新练习
- 使用 IndexedDB 保存笔迹与批改记录，备份包含新笔记本，兼容原有进度与旧版备份
- 提交后自动批改；学生只选择错因，不需要自行判定对错
- 模糊笔迹、模型加载失败、未知释义均暂不计错；可以标记识别有误
- 待核实题目可“暂存并跳过”，不记对错；刷新后恢复尚未完成的本题笔迹、批改结果和错因
- 使用 PaddleOCR.js 0.4.2 + PP-OCRv5 在浏览器 Worker 中本地识别，无 API Key、按次费用或 Token 费用
- 模型、运行时和代码从当前网站下载，作答笔迹不上传；没有云端付费回退
- 英文拼写精确核对，保留词间空格；中文采用预设释义和常见同义表达，未知表达不强行判错
- 首次联网打开后可通过 Safari“添加到主屏幕”使用

## 当前交付状态

浏览器交互回归已验证独立草稿、撤销清空、历史、错因、未识别状态和竖屏布局。真实本地引擎已使用中英文渲染文字样本跑通，验证识别结果和自动核对，无外部推理请求。渲染文字测试不代表本人手写准确率，实体 iPad/Apple Pencil 尚待用户试用。

`/api/` 路由在免费版一律返回 410；服务端已移除付费识别实现，即使环境里保留旧的云端密钥，也不会触发付费识别。GitHub Pages 可以直接运行本版，不需要服务器。继续使用原 GitHub 仓库与原网址，不接入阿里云，也未执行腾讯云迁移。

## 用户使用步骤

1. 在原学习台“进度”页先导出备份，保存到 iPad“文件”。
2. 用 Safari 打开更新后的学习台；若仍显示“随手写”输入框，请关闭后重新打开或刷新。
3. 点“单词”，建议先选“中 → 英”，看中文写英文。
4. 在答题纸上用 Apple Pencil 直接书写，不用输入框、不需要开启系统随手写。默认仅笔书写，可取消勾选后用手指写。
5. 点“提交批改”。首次需要下载约 46MB 的模型和运行组件，请保持页面打开；耗用网络流量，无识别接口费用。
6. 查看识别内容和结果。识别不清时重写；识别与原笔迹不符时点“识别有误”。
7. 答错后选择错因，点“保存并下一题”；答对可直接保存下一题。
8. 展开“答题记录”看旧笔迹、错因，或重新练习。定期导出新版备份。

```powershell
$env:PREVIEW_PORT=4179; node local-server.mjs
```

浏览器交互回归：启动本地服务后设置 `NOTEBOOK_TEST_URL`，执行 `npm run test:notebook`。真实 OCR 引擎检查：本地端口 4183 上执行 `npm run test:ocr`，并阻断外部网络，确认全部推理在本机完成。需要 Playwright 和 Edge；旧的 `scripts/test-browser.mjs` 为已弃用界面测试。

## 模型与运行时

`npm run prepare:ocr` 从官方地址取得 PP-OCRv5 mobile 检测/识别模型（合计约 21.5MB），复制匹配的 ONNX Runtime WASM，打包 PaddleOCR.js 到 `site/vendor/paddleocr/`。收据记录模型大小和 SHA256；许可文本一并保留。

固定采用单线程 WASM，不依赖 WebGPU 或跨域隔离。Worker 的 ImageData 适配器将答题图直接转成 OpenCV Mat，避免在 Worker 中调用 DOM；每次预测结束释放 Mat。超时或取消会终止空闲 Worker，不会切换到云端。
