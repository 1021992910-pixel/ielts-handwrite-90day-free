## 10.17C：恢复不会作答入口（当前版本）

只恢复提交前按钮“暂时不会，查看答案并记录复习”；核对后错因“完全不会”保留。这是功能入口，不属于要删除的冗余说明。后续精简提示不得擅自改名、合并或移除已确认的功能按钮。练习机制、判分、记录和其余界面不变。版本参数 `1017C`，缓存 `ielts-handwrite-words-v14`。

## 10.17B：精简单词页面与二元核对（历史版本）

移除单词作答页的步骤、规则说明、自动保存文案及额外提示框。保留后台草稿存储、真实错误提示、两行答案对照、拼写标色和唯一“下一题”。错因按 1、2、3… 编号多选，保留“完全不会”。

键盘输入的中文释义在参考答案及同义表中匹配则答对，其余非空内容按答错处理，不再产生“待核实”状态。旧未完成的键盘待核实答案恢复为锁定的错题；旧已完成记录不覆盖，展示及错词汇总统一归为错题。此规则不代表 AI 语义判断，未收录的同义表达仍可能误判。其他模块的旧笔迹判分保持不变。

版本参数 `1017B`，缓存 `ielts-handwrite-words-v13`。继续使用原 GitHub Pages、原本地存储和原每日 30 词/错词循环机制，无新增接口费用。

## 10.17A：有限 30 词练习与统一错词本（历史版本）

每日练习固定选出最多 30 个不重复词。首轮结束自动衔接本次未答对/待核实词的后续轮次，只循环仍未答对的词，全部独立答对后停止并显示完成，不自动添加下一组词。未完成练习跨刷新保留，完成后刷新不重新开练；另一天或主动“再练一组 30 词”才创建新的日常练习。每一轮草稿以 session/round/word 隔离，原回答不可修改重交。旧版未完成键盘草稿可迁移，旧词库与笔迹不删除。

单词页“错词本”入口从已有 IndexedDB 作答记录汇总，不重复罗列同一词。“完全不会”用橙色边框、底色及文字徽标区分；本次答对后仍保留原错词和错误历史，改标“本次已答对”，供以后复习。进入错词本直接开始独立默写，无额外开始/错题重考按钮；列表折叠，避免默认暴露答案。错词本自身同样未答对词自动衔接轮次，全部答对即停，再点击错词本可开新次练习。日常与错词练习分开保存，来回切换不会重置未完成的日常练习。

`word-practice.js` 提供会话、次序校验及错词汇总；保存过的完成事件按 attempt ID 幂等重放，避免重复计数并恢复保存中断。备份继续携带整个 state 和新旧 notebook。没有 AI/API 调用。`npm run test:word-session` 在真实表单、本地规则与存储上验证 30 词、反复巩固、结束、恢复、保留原错误、颜色标记与直接错词复习；`WORDS_BROWSER=webkit` 用于移动 WebKit 检查，实体 iPad 仍需用户验收。`WORDS_UPGRADE_PENDING=1 npm run test:word-cache` 验证旧版未完成的答案/错因迁移后保持锁定。版本参数 `1017A`，缓存 `ielts-handwrite-words-v12`；以下为历史版本说明。

## 用户使用步骤

1. 在原学习台“进度”页先导出备份，保存到 iPad“文件”。
2. 用 Safari 打开更新后的学习台；若仍显示“随手写”输入框，请关闭后重新打开或刷新。
3. 点“单词”，建议先选“中 → 英”，看中文写英文。
4. 在答题纸上用 Apple Pencil 直接书写，不用输入框、不需要开启系统随手写。默认仅笔书写，可取消勾选后用手指写。
5. 点“提交批改”。首次会准备识别组件，显示简洁状态；“查看进度”内可以查看下载详情。可点“取消等待”，之后点“重试批改（保留笔迹）”，不需要重新写。完整组件会缓存，浏览器清理缓存/存储或组件升级后可能需要重新下载。只有网络下载流量，无识别接口费用。
6. 查看识别内容和结果。识别不清时重写；识别与原笔迹不符时点“识别有误”。
7. 答错后选择错因，点“保存并下一题”；答对可直接保存下一题。
8. 展开“答题记录”看旧笔迹、错因，或重新练习。定期导出新版备份。

## 模型与运行时

`npm run prepare:ocr` 从官方地址取得 PP-OCRv5 mobile 检测/识别模型（合计约 21.5MB），复制匹配的 ONNX Runtime WASM 和原版 OpenCV，打包不内嵌 OpenCV 的 PaddleOCR.js 到 `site/vendor/paddleocr/ocr-sdk-lite.js`。生成 `ocr-assets-manifest.js`，逐组件记录固定版本国内源、本站回退路径、大小和 SHA-256；许可文本一并保留。旧 SDK 仅为旧页面兼容保留，新版不请求它。

固定采用单线程 WASM，不依赖 WebGPU 或跨域隔离。轻量 Worker 先下载并检查组件大小，将字节保存到独立 IndexedDB `ielts-ocr-components`（不可用时尝试 CacheStorage `ielts-ocr-models-v1`），再通过 Blob URL 导入 SDK/初始化本机模型，避免首次访问没有 Service Worker 控制时重复下载。模型存储与笔记本、app-shell 分离，不进入用户备份，Service Worker 不再重复缓存大型下载。Worker 的 ImageData 适配器将答题图直接转成 OpenCV Mat，避免在 Worker 中调用 DOM；每次预测结束释放 Mat。超时或取消会终止本次 Worker；成功后复用已初始化引擎，不会切换到云端。
